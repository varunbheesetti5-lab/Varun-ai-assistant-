# Palette UX Journal

## 2024-07-27 - [A11y/UX Improvement for AI Assistant]
**Learning:** Screen readers and keyboard users need explicit cues (like `.sr-only` labels and ARIA attributes) to navigate chat inputs and copy code blocks efficiently, ensuring accessibility is not an afterthought but integrated gracefully into the UI.
**Action:** Always include a screen-reader-only label for inputs, ARIA-labels for icon-only buttons, and keep clipboard functions accessible and precise by excluding button text from copy targets.
