## 2026-07-09 - Accessibility and Micro-UX in Single-File Assistant
**Learning:** In a single-file application where elements are dynamically generated (like code blocks with copy buttons), accessibility attributes (ARIA labels, titles) must be set programmatically at the point of creation. Static HTML accessibility is insufficient for a dynamic chat experience. Also, robust copy-to-clipboard functionality should target specific sub-elements (like <code>) to avoid capturing UI text (like "Copy" button labels) that may be siblings within the same container.
**Action:** Always verify what is being copied to the clipboard when UI elements like buttons are nested inside the selectable area. Ensure dynamic feedback (e.g., "Copied!") is reflected not just in text but also in ARIA labels and titles for consistent UX across different input methods.
