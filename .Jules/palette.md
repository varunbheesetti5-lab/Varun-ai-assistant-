## 2024-08-03 - [Accessible Code Copying and Dynamic Focus Feedback]
**Learning:** Copy buttons inside dynamically formatted `<pre>` blocks often capture the copy button's own text (like '📋 Copy' or '✅ Copied!') if they target `pre.textContent`. Targeting the nested `<code>` element via `innerText` keeps the clipboard payload clean and preserves original formatting/newlines. Additionally, dynamic controls created on-the-fly inside code blocks require explicit focus/blur styling (`onfocus`/`onblur`) alongside matching ARIA and tooltip labels to ensure keyboard-only users get appropriate visual cues.
**Action:** Always target `code.innerText` instead of `pre.textContent` when copying from structured code containers, and dynamically bind `onfocus` and `onblur` event handlers to simulate `:focus-visible` focus outlines on custom injected absolute-positioned buttons.
