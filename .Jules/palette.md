## 2025-02-15 - [Dynamic Code Copier & Focus Accessibility]
**Learning:** In single-file HTML applications, copying `<pre>` text content directly can capture dynamic sibling UI elements like "Copy" buttons. This can corrupt the clipboard payload. Targeting the `<code>` sub-element using `innerText` guarantees that only the user-facing text formatting (with line-breaks intact) is copied. Additionally, since inline-styled dynamic elements cannot use standard CSS pseudo-classes, we must apply focus/blur event listeners in JavaScript to simulate the `:focus-visible` state.
**Action:** Always target specific nested element innerText for clipboard copying and utilize JavaScript event listeners (`onfocus`/`onblur`) to manage focus-visible accessibility rings on dynamically injected elements.
