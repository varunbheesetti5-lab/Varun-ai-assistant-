## 2026-07-11 - Accessibility Utility for Single-File HTML Project
**Learning:** In a standalone HTML project without a CSS framework, adding a `.sr-only` utility class is essential for providing context to screen readers (e.g., for icon-only buttons or form labels) without affecting the visual layout.
**Action:** Always include the `.sr-only` class in the `<style>` block when implementing accessibility improvements in single-file projects.
