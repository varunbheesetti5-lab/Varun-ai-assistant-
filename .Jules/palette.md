## 2026-11-11 - Accessible Chat Controls & Dynamic Status Announcements
**Learning:** Icon-only action buttons (like `#sendButton`) and dynamic status indicators (like `#apiStatus`) require explicit ARIA attributes (`aria-label`, `role="status"`, `aria-live="polite"`) to ensure assistive technology announces actions and state changes accurately. Additionally, initializing default disabled UI states through synthetic events (such as `dispatchEvent(new Event('input'))`) prevents discrepancy between JS state and visual presentation without hardcoding disabled attributes.
**Action:** Always provide descriptive ARIA labels/tooltips to icon-only controls, use live regions for dynamic connection/status badges, and trigger synthetic events on initialization to synchronize interactive states cleanly.
