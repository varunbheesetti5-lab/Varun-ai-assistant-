## 2024-07-26 - [Dynamic Accessibility Tooltips & State Updates]
**Learning:** In dynamically updated UI components (like code block copy buttons), relying solely on `aria-label` is insufficient because mouse users also need to see visual feedback matching the screen reader announce. Updating both `aria-label` and the native `title` attribute in tandem on dynamic text changes ensures seamless visual-mouse and auditory-keyboard tooltips. Additionally, using standard CSS focus rings rather than dynamic inline JS styles reduces code complexity and enhances maintainability.
**Action:** When writing dynamic states (e.g., loading, success, error toggles), always bundle `aria-label` and `title` updates together, and define their visual focus outlines (`focus-visible`) in the core style sheet via modular classes rather than inline scripts.
