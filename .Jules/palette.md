## 2026-07-21 - Preventing UI Pollution in Code Block Clipboard Copying
**Learning:** Using `pre.textContent` or `pre.innerText` directly to copy code blocks can inadvertently capture sibling or descendant interactive UI elements (such as 'Copy' buttons) that have been dynamically appended to the container. This pollutes the clipboard with UI text (e.g. copying "📋 Copy" or "✅ Copied!" along with the code), creating a frustrating user experience.
**Action:** Always scope the target of clipboard operations to the specific semantic element holding the text (e.g., query for the descendant `code` element inside `pre`) instead of reading from the parent container. Also ensure that the copy action programmatically updates ARIA labels and titles to notify assistive technology users of the state change.
